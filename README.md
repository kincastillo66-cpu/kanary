# Kanary 

**Kanary** es la billetera digital de autocustodia para enviar y recibir dólares digitales (USDC y USDT) en la red Base usando solo un `@alias`. 

Disfruta de pagos P2P instantáneos, cobros con QR dinámico en el Modo Punto de Venta (POS) y máxima privacidad, sin bancos ni intermediarios. Descarga la app oficial de Kanary aquí y pronto en Play Store. 🤎
